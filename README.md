# Chain of Command

Playable releases for Apple Silicon Macs running macOS 26 or later.

[Download the latest release](https://github.com/MrBiscuit/chain-of-command-releases/releases/latest).

For version 0.1.0, download **both disk-image parts into the same folder**. After both finish, open the `.dmg`, drag **Chain of Command.app** to Applications, then open the app.
All runtime models, textures, artwork, fonts, catalog data and audio are included. The app is Developer ID signed, Apple-notarized and stapled for offline verification.

This repository hosts game downloads. The source repository is private.
